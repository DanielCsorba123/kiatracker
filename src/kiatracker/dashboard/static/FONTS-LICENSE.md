# Fonts

Served by the dashboard itself (no Google Fonts requests, so visitors' IP addresses aren't shared and it works offline).

- `young-serif.woff2`: [Young Serif](https://github.com/noirblancrouge/YoungSerif) by Bastien Sozeau / Noir Blanc Rouge, SIL Open Font License 1.1. Latin subset made with fontTools from the Google Fonts repository.
- `hanken-grotesk-var.woff2`: [Hanken Grotesk](https://github.com/marcologous/hanken-grotesk) by Alfredo Marco Pradil and Hanken Design Co., SIL Open Font License 1.1. Variable weight, Latin subset made with fontTools from the Google Fonts repository.
